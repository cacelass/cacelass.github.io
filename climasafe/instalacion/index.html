ClimaSafe · instalación

Get ClimaSafe
running in minutes.

Two ways to run the full prediction pipeline (ML models, API, Telegram bot, MCP server): a single Docker command or pip on any machine with Python ≥ 3.12.

02
docker

Docker

easiest

Run the image

A single command starts the web server with pre-trained models:

docker run -d --name climasafe \
  -p 8080:8080 \
  ghcr.io/cacelass/climasafeai:latest

Then open http://localhost:8080. No training, no configuration needed.

compose

With Docker Compose

Clone the repo and use compose for a more controlled setup:

git clone https://github.com/ANFAIA/ClimaSafe.git
cd ClimaSafe
docker compose up -d          # web server only

Data persists in named volumes between restarts. Start fresh with docker compose down -v.

compose + github

Build from GitHub

No need to clone — this compose file builds directly from the repo:

curl -O https://raw.githubusercontent.com/ANFAIA/ClimaSafe/main/compose.gh.yml
docker compose -f compose.gh.yml up -d
services:
  climasafe:
    build:
      context: https://github.com/ANFAIA/ClimaSafe.git#main
      dockerfile: Dockerfile
    ports:
      - "8080:8080"
    volumes:
      - climasafe-data:/app/data
      - climasafe-models:/app/models
    env_file: .env

  bot:
    profiles: ["bot"]
    build:
      context: https://github.com/ANFAIA/ClimaSafe.git#main
      dockerfile: Dockerfile
    command: climasafeai-bot
    env_file: .env
    depends_on: [climasafe]

volumes:
  climasafe-data:
  climasafe-models:
optional

Telegram bot

The bot runs in a separate profile and needs a token from @BotFather:

cp .env.example .env           # add your TELEGRAM_BOT_TOKEN
docker compose --profile bot up -d
03
pip

Option B — pip (Python ≥ 3.12)

flexible

Install from GitHub

# create and activate a virtual environment
python3 -m venv .venv && source .venv/bin/activate
pip install --upgrade pip

# install with the extras you need
pip install "climasafeai[api,supervisado,redes_neuronales,mlflow_tracking]" \
    git+https://github.com/ANFAIA/ClimaSafe.git

Available extras: api (FastAPI/uvicorn), supervisado (XGBoost/LightGBM/SHAP), redes_neuronales (PyTorch/LSTM), mlflow_tracking, voice (STT/TTS), rag (embeddings), onnx.

Installed CLI tools:
Command What it does
climasafeai-botStarts the Telegram bot (needs TELEGRAM_BOT_TOKEN)
climasafeai-mcpMCP prediction server (Claude Desktop / Cursor)
04
desarrollo

For developers

source

Clone & set up

git clone https://github.com/ANFAIA/ClimaSafe.git
cd ClimaSafe
./init.sh                       # full environment check
# or: uv sync --extra dev --extra supervisado
source .venv/bin/activate

Once set up, use the Makefile:

make run          # full pipeline (data → train → predict → reports/)
make serve        # FastAPI at localhost:8000 (interactive docs at /docs)
make test         # full pytest suite
make lint         # ruff check
make mlflow       # MLflow UI at localhost:5000

06
mcp

MCP via web — zero install

The ClimaSafe MCP server also runs as a web endpoint hosted on GitHub Pages. Point your MCP client at the URL and start making predictions — no local installation needed.

endpoint

Web endpoint

Add this to your MCP client configuration:

{
  "mcpServers": {
    "climasafe": {
      "url": "https://cacelass.github.io/climasafe/mcp/"
    }
  }
}
local

Local MCP server

Or install locally for full offline access:

pip install "climasafeai[mcp]" \
    git+https://github.com/ANFAIA/ClimaSafe.git
climasafeai-mcp            # stdio server for Claude Desktop

Works with Claude Desktop, Cursor, Windsurf and any MCP-compatible client.
