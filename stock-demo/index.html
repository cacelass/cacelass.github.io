Stock-Market-Prediction

Predicción de tendencia bursátil con ML honesto

Este demo muestra las predicciones actuales del modelo entrenado. Los datos son de producción real (2007–2026) con 175 tests, validación walk-forward y anti-fuga de datos en código.

Ver Predicciones ← al proyecto

¿Qué predice?

Si el precio de un activo sube más del 2% en los próximos 5 días. Clasificación binaria (sube >2% / no sube >2%).

Modelo

Random Forest (max_depth=5, min_samples_leaf=50, seed=42) + features de sentimiento VADER con noticias reales de NewsAPI.ai.

Validación

Walk-forward 3-fold expanding window. Tuning con Optuna sobre AUC walk-forward. Split temporal 80/20 sin shuffle.

Tickers

AAPL · MSFT · GOOGL · AMZN · META · TSLA · NVDA

Predicciones actuales

—

Última predicción por ticker (modelo individual, no global). Probabilidad de subida y bajada.

Nota sobre el enrutamiento

NVDA no tiene señal propia en el modelo individual (AUC walk-forward < 0.55). El sistema usa el modelo global pooled como fallback. Las predicciones de NVDA aquí son del modelo global.

⚠️ Veredicto honesto

La estrategia de trading con estas predicciones no supera a buy&hold out-of-sample. La cartera con costes (0.1% comisión + 0.05% slippage) da 53.59% vs 281.70% de buy&hold. Este proyecto demuestra rigor técnico, no rentabilidad.

Avisos importantes

🔒 No es inversión

Las predicciones son resultados de un modelo académico. No las uses para tomar decisiones financieras reales.

📉 Bajo señal

Los mercados financieros tienen relación señal/ruido muy baja. Un AUC de 0.626 ya es un resultado bueno para este dominio.

📅 Datos hasta 2026

Los modelos están entrenados con datos históricos hasta marzo 2026. Las predicciones pueden no reflejar eventos recientes.
